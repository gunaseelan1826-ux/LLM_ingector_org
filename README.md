# LLM Prompt-Injection / Jailbreak Detector

An AI-based cybersecurity tool that scans user prompts destined for an
LLM-powered chatbot and flags prompt-injection / jailbreak attempts
before they reach the model.

## Project Structure
```
LLM_Detector/
├── app.py               Flask web server
├── train.py              Trains the TF-IDF + Logistic Regression model
├── predict.py             Loads model, classifies text, detects patterns
├── generate_dataset.py    Generates dataset.csv (already run once)
├── dataset.csv            Labeled training data (safe=0, dangerous=1)
├── model.pkl               Trained classifier (generated by train.py)
├── vectorizer.pkl          Trained TF-IDF vectorizer (generated by train.py)
├── requirements.txt
├── templates/
│   ├── index.html          Detector UI
│   └── logs.html           Logs viewer UI
├── static/
│   └── style.css
└── logs.db                 Auto-created SQLite log (created on first run)
```

## Setup

```bash
pip install -r requirements.txt

# (Optional) Regenerate the dataset
python generate_dataset.py

# Train the model (creates model.pkl and vectorizer.pkl)
python train.py

# Run the app
python app.py
```

Then open **http://127.0.0.1:5000** in your browser.

## How It Works

1. **Input Validation** — user prompt is captured from the web form.
2. **Text Preprocessing + TF-IDF** — the prompt is vectorized using a
   TF-IDF representation (unigrams + bigrams).
3. **ML Classifier** — a Logistic Regression model trained on labeled
   safe/dangerous prompts predicts a class + confidence score.
4. **Rule-based Pattern Matching** — a regex layer independently flags
   known jailbreak signatures (e.g. "ignore previous instructions",
   "DAN", "developer mode", "reveal your system prompt") for
   explainability, and acts as a defense-in-depth safety net.
5. **Decision** — if flagged Dangerous, the prompt is blocked and a
   warning is shown instead of being forwarded to the AI model.
6. **Logging** — every analysis (prompt, prediction, confidence,
   matched patterns, timestamp) is saved to `logs.db` (SQLite) and
   viewable on the `/logs` page.

## Extending This Project
- Swap Logistic Regression for a fine-tuned DistilBERT classifier for
  higher accuracy on paraphrased/obfuscated attacks.
- Add embedding-similarity search (e.g. sentence-transformers) against
  a bank of known jailbreak prompts for semantic (not just keyword)
  matching.
- Add a REST API endpoint (`/api/analyze`) so this can sit as a
  middleware in front of a real chatbot pipeline.
- Add rate-limiting / IP tracking in logs.db to catch repeated
  probing attempts from the same source.
